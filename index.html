Enviar nova construção

1. Monte a construção no miceditor e copie o XML do mapa (menu de exportar/copiar XML).

2. Preencha os campos abaixo e clique em enviar — isso vai abrir uma página do GitHub pra você confirmar (é necessário ter uma conta no GitHub, gratuita).

Observação: o campo "nick" é só uma identificação simples, não é uma conta de verdade — qualquer pessoa pode digitar qualquer nome ali. A validação real de quem enviou é feita pela sua conta do GitHub, que fica registrada automaticamente quando você confirma o envio.
